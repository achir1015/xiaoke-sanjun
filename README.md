# 小柯機器人三軍棋遊戲

<img src="build/icon.png" width="160" align="right" alt="小柯機器人三軍棋遊戲">

3D 立體陸海空三軍棋（二人對戰）：陸軍、海軍、空軍每方 33 顆棋子；暗棋裁判制與明棋、真人對 AI、真人對真人（遠端連線＋語音）、AI 對 AI，
AI 只根據公開資訊推算對方暗子，並從累積的棋譜學習。

**遊戲開發：吳玉柱 先生 與 Claude AI Opus 5.5**

## 功能

- **三種對戰**：真人對 AI（入門～大師五種難度）、真人對真人（6 位數房號邀約遠端棋友、文字與語音聊天）、AI 對 AI 觀戰。
- **布陣**：點一顆棋子再點另一顆或空格就能互換、移動；經典布陣、隨機、AI 軍師推薦；可儲存自己的布陣。不合規則時會說明原因。
- **暗棋裁判制**：看不到對方棋子，只公布交戰勝負；偵察機可以翻開對方棋子；總司令陣亡亮出軍旗。也可以選「明棋」練習。
- **敵情推算與速算**：根據起始位置、走法（海上是軍艦、會飛的是飛機、鐵路轉彎是工兵）、交戰結果與偵察，用多次抽樣推算每顆暗子的機率，
  在棋盤上標示並列出敵方剩餘兵力。AI 也只用同樣的資訊（絕不偷看），再對每一種可能的布陣做 α-β 搜尋、取平均最好的一步。
- **棋譜累積**：每局自動收錄，可重播、匯出、匯入；AI 從棋譜學習對手常用的布陣位置與打贏過的布陣。
- **AI 軍師陪同**：20 位男英雄、20 位女佳人頭像、30 位男女 AI 軍師。開局前選頭像與軍師；對局中可請教、可換軍師；
  主位可由 AI 軍師代打，之後再交還主位。有 Anthropic API 金鑰時以 Claude 白話解說。
- **教學**：19 課三軍棋教學（動畫小棋盤＋語音講解＋練習）；系統功能說明（語音＋文字）。
- **3D 場景**：沙盤陸地、起伏的海面、外海航道、三座鐵橋、港口燈塔、機場塔台、飄揚的軍旗；陸軍方塊、隨浪搖晃的軍艦、懸空的飛機；
  交戰火花、炸彈爆炸、砲彈與偵察動畫。
- **背景音樂**：20 首原創軍樂風格音樂（每首 3 分多鐘），音樂與音效各有直立音量滑桿（往上大聲）。

## 棋盤

13 列 × 9 行。C～G 行是陸地（同陸軍棋：鐵路、公路、行營、大本營，另有港口）；B、H 行是近海（底線為飛機場）；
A、I 行是外海航道；中間第 7 列是海峽，只有 C7、E7、G7 三座鐵橋。

## 規則摘要

- 每方棋子：陸軍 21（總司令、軍長、師長、旅長各 1，團長、營長、連長、排長、工兵、高射炮、炸彈、地雷各 2，軍旗 1）、
  海軍 10（主力艦、巡洋艦、砲艦、驅逐艦、潛水艇各 2）、空軍 2（偵察機、戰鬥機各 1）。
- 陸軍：總司令＞軍長＞師長＞旅長＞團長＞營長＞連長＞排長＞工兵；同級同歸於盡。公路一步、鐵路直線不限距離、只有工兵能在鐵路上轉彎；
  只能經由鐵橋過海峽（要在橋上停一步）；行營裡的棋子不能被攻擊；進大本營不能再移動。
- 海軍：主力艦＞巡洋艦＞砲艦＞驅逐艦＞潛水艇；潛水艇主動攻擊時能擊沉主力艦、巡洋艦、砲艦，但遇上驅逐艦必沉。
  近海一次一格、外海航道直航；可以開進港口，不能上岸。砲艦可炮擊緊鄰海岸的陸地（贏了留在海上）。
- 空軍：沿直線或斜線飛行並可飛越棋子（戰鬥機 3 格、偵察機 4 格），不能降落大本營。戰鬥機能吃一般陸軍與軍艦、能炸地雷，
  但會被高射炮、砲艦擊落；偵察機不交戰，只會翻開對方棋子，任何棋子攻擊它都會被打下來。
- 高射炮：擊落來犯的飛機，也能射擊旁邊一格海上或機場上的敵機；陸戰時和連長一樣大。
- 炸彈碰到任何棋子同歸於盡（不能奪旗）；地雷碰到一般棋子同歸於盡，工兵、戰鬥機能清除地雷。
- 布陣：軍旗在大本營、地雷在陸地最後兩排、炸彈不在第一排、行營空著、軍艦在海上、飛機在機場。
- 奪下軍旗或對方無棋可走即獲勝；連續 50 回合沒有交戰判和。

規則參考：[code-fans/kriegspiel](https://github.com/code-fans/kriegspiel)（陸軍棋）＋台灣傳統三軍棋（陸海空軍棋）。

## 開發

```bash
npm install
npm start            # 開發模式
npm test             # 規則、AI、推算、教學單元測試
node e2e/smoke.mjs   # 單機端對端測試
node e2e/net.mjs     # 雙實例連線測試（本機配對伺服器）
npm run dist:win     # 建置 Windows 安裝檔
python android/build.py install   # 建置 Android APK 並安裝到 USB 連接的手機（加 debug 可實機測試）
node e2e/phone.mjs   # 手機實機測試（除錯版 APK）
node e2e/ios.mjs     # iPhone／iPad 版面測試（Chrome 模擬）
node e2e/web.mjs     # 線上版測試（照網站路徑排好；可帶正式網址參數）
```

素材產生：`python scripts/gen_music.py`（背景音樂）、`node scripts/gen_portraits.mjs`（頭像）、`python scripts/make_icon.py`（圖示）。
